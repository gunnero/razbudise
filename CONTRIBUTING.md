# Contributing

RazbudiSe is publicly source-visible but is not currently licensed for unrestricted reuse or redistribution.

Before proposing a change:

1. Open a focused issue that contains no credentials, customer data, private topology, or unpublished editorial material.
2. Keep changes small and product-focused.
3. Add or update tests for behavior changes.
4. Run the backend tests and Pint, then the frontend tests, lint, and production build.
5. Confirm that generated files, local environments, browser traces, screenshots, and operational artifacts remain untracked.

Pull requests should explain the problem, implementation, test evidence, security considerations, and any migration or rollback implications. Contributions are accepted only after review and do not change the repository’s licensing status.
